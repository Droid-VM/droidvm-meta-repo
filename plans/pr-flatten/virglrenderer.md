### Consider dropping from the PR

1. **IB fault-scan probes (4b95636 half, → D5)**: `kgsl_nctx_fault_low32()` with a hard-coded default fault address `0x008fd438`, `kgsl_scan_fault_addresses()`, `kgsl_scan_reg_to_mem_addresses()`, the IB-WINDOW dump keyed on the literal IB sizes 0x7ffc / 0x85e4 ("System Settings reproducibly faults after…"), and the extra `kgsl_cache_clean_inv` scrubs after those reads. Investigation scaffolding for one bug; the pre-graft NCTX_IB_CHECK / NCTX_IB_SCAN blocks they hang off are the same kind of thing (not in range, but the owner may want a D cleanup that removes all of it).
2. **KGSL_DIAG counters (939b20c, → D5)**: process-wide counters + `kgsl_diag_log()` to `ANDROID_LOG_ERROR` tag "crosvm", **enabled by default** (`CROSVM_DRM2KGSL_DIAG=0` to silence — c901132 says the launcher sets it specifically to turn them off). Drop, or default-off, or fold the wait-latency bits into D4 as `drm_dbg`.
3. **A/B env knobs**: NCTX_RELAX_SLICE (turns a security check into a warning), NCTX_NO_WAITTS / NCTX_WAITTS (D4), NCTX_NO_FENCE (pre-graft). Decide which survive.
4. **VENUS-DIAG `fprintf(stderr, …)` in src/venus/vkr_virgl_adapter.c (73d830b)**: replaced three `virgl_error()` calls with raw stderr prints and added an *unconditional* print on every `get_blob()` and every `set_guest_blob_fd()`. Restore `virgl_error()`, delete the two hot-path prints (V5).
5. **`#if 0` block in src/venus/vkr_library.c** (`vkr_library_load_orig`, 52 lines) — dead upstream copy kept "for reference" (V3).
6. **Dead code left by 8740567 in drm2kgsl_renderer.c** (compile as unused statics): `kgsl_alloc_arena_bo()` (D2, no callers), `kgsl_alloc_thp_bo()` + its 1e5568d cache-clean hunk, `kgsl_dma_heap_alloc()`, `dma_heap_path`/`kctx->dma_heap_fd` (still opened at every context create and *fails create if /dev/dma_heap/system is absent* although nothing uses it), and the arena-v2 run-list remnants (`struct kgsl_object::runs/nr_runs`, `kgsl_vbo_bind_runs()`, `kctx->arena`, the `!obj->mem_id` re-stitch branches in GEM_SET_IOVA/map_object/get_blob, `struct msm_gem_new_run` + "Arena v2 extension" comment in src/drm/msm/msm_proto.h). Mostly pre-graft, so not "in" this range, but a D commit "drm2kgsl: remove the host allocator and arena-v2 leftovers" would be a natural companion to D7.
7. **src/venus/vkr_metal_helpers.{h,m}, vulkan_metal.h, vulkan_beta.h** — Apple-only upstream files; keep if V1 is to be pristine, otherwise trim.
